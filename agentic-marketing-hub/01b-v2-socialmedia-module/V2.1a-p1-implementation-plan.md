### **4\. Technical Architecture (Phase 1\)**

This phase solidifies the CrewAI-centric architecture.

#### **Frontend**

- **Framework:** React/TypeScript with Next.js.
- **Canvas:** Fabric.js.
- **State Management:** Zustand.
- **Real-time Communication:** A WebSocket client (`socket.io-client`) will be integrated to listen for updates from the CrewAI service.

#### **Backend**

- **Framework:** The existing Express/Node.js backend will be enhanced.
- **AI Core:** A new, separate **CrewAI service (Python)** will be created and containerized with Docker. This service will expose a WebSocket server to communicate with the main backend.
- **Communication:** The Express backend will act as a proxy. When it receives a request to generate content, it will forward the task to the CrewAI service via an internal API call or a message queue (like Redis pub/sub). The CrewAI service will then push progress and results back to the frontend via the WebSocket connection.

#### **CrewAI Agent Architecture**

```
# In the CrewAI Python Service
from crewai import Agent, Task, Crew

# Agent for analyzing property data from the database
property_analyst = Agent(
    role='UK Property Marketing Analyst',
    goal='Analyze property data to extract key selling points and compliance details',
    backstory='An expert in the UK property market, skilled at identifying what makes a property appealing and what is required for legal compliance.'
)

# Agent for writing creative and compliant marketing copy
content_creator = Agent(
    role='Creative Property Marketing Copywriter',
    goal='Write compelling, engaging, and compliant marketing content for social media',
    backstory='A professional copywriter with a flair for real estate and deep knowledge of ASA advertising standards.'
)

# Agent for validating the content against UK regulations
compliance_checker = Agent(
    role='ASA Compliance Validation Specialist',
    goal='Ensure all generated marketing content strictly adheres to UK property advertising regulations',
    backstory='A meticulous expert on ASA guidelines, dedicated to preventing legal and reputational risks.'
)

# The Crew that orchestrates the workflow
property_marketing_crew = Crew(
    agents=[property_analyst, content_creator, compliance_checker],
    tasks=[...],
    verbose=True
)

```
