## How to verify locally

1. Restart Vite (`npm run dev` from repo root).
2. Home: type a property query → pills + **View as**.
3. Search → result cards show fact badges (Clear / Flagged / Unresolved).
4. Open a card → **Proptii government data** module → **Open report** → change View as (facts stay, lens text changes).
5. Home: search `What are my deposit rights?` → Know Your Rights enquiry panel.
6. Home: search `football scores` → off-topic panel.
