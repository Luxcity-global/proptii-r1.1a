Proptii email previews

Each file uses the referencing email layout: logo, orange button, sign-off, and footer. Names and addresses are samples.

  1. New message
    A user receives a new conversation message. Guests get a claim link; registered users get a login link.
  2. Claim account
    A guest is invited to claim a Proptii account after receiving messages.
  3. Referencing passport shared (existing account)
    A tenant shares a referencing passport with a landlord or agent who already has an account.
  4. Referencing passport shared (no account)
    A tenant shares a referencing passport with someone who does not have an account yet.
  5. Referencing request
    A landlord asks a tenant to complete referencing.
  6. Referencing application to the agent
    The referencing application summary prepared for the agent. This is the layout the other emails now follow.
  7. Referee questionnaire
    A referee is asked to complete a reference form.
  8. Guarantor questionnaire
    A guarantor is asked to complete a confirmation form from the referencing email endpoint.
  9. Guarantor invitation
    A tenant invites a guarantor with a secure form link.
  10. Guarantor invitation sent (tenant copy)
    The tenant is told that the guarantor invitation went out.
  11. Guarantor form completed (tenant)
    The tenant is told their guarantor submitted the form.
  12. Guarantor form completed (guarantor receipt)
    The guarantor receives a receipt after submitting.
  13. Viewing request (agent)
    A tenant requests a viewing. The agent receives this email.
  14. Viewing request (tenant confirmation)
    A tenant requests a viewing and receives a copy of what they submitted.
  15. Viewing scheduled by landlord
    A landlord or agent schedules a viewing from Request Viewing and emails the applicant.
  16. Viewing confirmed
    A landlord confirms a viewing, or schedules one from a pending request. The tenant is notified.
  17. Viewing reschedule
    Either side asks to move a viewing. The other party receives this notice.
  18. Viewing cancellation
    Either side cancels a viewing and the other party is notified.
  19. Contract for review
    A landlord sends a contract document for the recipient to review. The PDF is attached.
  20. Contract test email
    The contracts page sends a test email with no attachment.
  21. Signed contract
    A signed contract PDF is emailed. The server sends this copy; the attachment is unchanged.
  22. Tenant invitation
    A landlord invites someone to create a tenant profile for a property.
