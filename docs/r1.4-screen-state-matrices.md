# r1.4 screen-state matrices

## Search bar (`SearchInput`)

| Boundary | Loading | Error / empty | Fallback |
|----------|---------|---------------|----------|
| Classifier (debounce) | “Understanding your search…” | No pills | Treat as `property_search`, navigate `/search?q=` |
| Audience toggle | n/a | “Not set” | Local context only |
| Submit | Button spinner | Empty query blocked | Always useful: search or enquiry UI |

## Results (`SearchResults`)

| Boundary | Loading | Error / empty | Fallback |
|----------|---------|---------------|----------|
| Scrape / Firestore | Existing skeletons / `SearchLoadingAnimation` | Existing empty / retry | Unchanged when flag off |
| Facts batch | Badge pulse placeholders | Absent key → **Unresolved** badge (never Clear) | Empty map if API fails outside DEV mocks |
| Enquiry intent | n/a | Off-topic / too-broad / answerable panels | CTA back to property search |

| Boundary | Loading | Error / empty | Fallback |

| Report open | Report panel loading | Empty facts → unresolved row | Close returns to details |
| Lens switch | “Updating…” on lens only | Keep previous lens on fail | **Facts fingerprint must not change** |
