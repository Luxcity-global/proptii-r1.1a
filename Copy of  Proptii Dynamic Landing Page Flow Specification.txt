Fallback & Edge Case Handling
* Direct / Unparameterized Traffic: If a user navigates to /welcome directly with no query string, the system cleanly defaults to the general property management layout and copy.
* URL Encoding & Special Characters: All query parameters undergo standard URI decoding to gracefully handle slashes (e.g., Estate agent / letting agent) and dashes (e.g., 21–50).
* CTA Continuation: Hidden fields and segment selections are preserved and forwarded from the landing page directly into the registration onboarding flow so the user never has to re-enter their role.
